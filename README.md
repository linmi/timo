# timo

Public dictionary resources for Lemo. The macOS application downloads a pinned edition once, verifies it locally, and then looks up definitions and etymologies offline.

## Download

[English Dictionary · 2026-09-02](https://github.com/linmi/timo/releases/tag/english-170b8bd75431)

Release assets:

- `EnglishDictionary.json`: 82,381 headwords, 36,880,502 bytes.
- `Dictionary-LICENSES.txt`: source attribution and applicable licenses.
- `dictionary-manifest.json`: edition, source checksums, output checksum and size.
